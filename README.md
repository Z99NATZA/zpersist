# zpersist

## Setup

```text
Requirements
==========

Docker Compose, Make, and a SQL Server instance reachable from the container.
```

```bash
# ---------- bash ---------- #

cp .env.example .env
```

## Run

```bash
# ---------- bash ---------- #

# http://localhost:8003
make run

# Stop
make down
```
